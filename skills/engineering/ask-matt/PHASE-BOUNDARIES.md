# 阶段边界（Phase boundaries）

一个**阶段（phase）**是会话内的一段工作 —— 追问、实现、QA。这个定义故意模糊：当你心想*"好，这段搞定了"*时，一个阶段就结束了。

**阶段边界**是两个阶段之间的缝隙，也是唯一适合做这类决策的位置。阶段中途没有决策可做 —— 要么继续，要么把剩余工作拆给 subagent。在阶段中途 compact 只会让 agent 断掉思路。

## 五个选项

| 选项            | 作用                                                          |
| --------------- | ------------------------------------------------------------- |
| **继续（Continue）** | 留在当前会话。完全不切换上下文。                          |
| **`/clear`**    | 清空上下文窗口，从零开始。                                      |
| **tuanzii:handoff** | 写一份可携带的 markdown 文件，用它可以在任何地方启动新会话。 |
| **Subagent**    | 把任务派到独立上下文窗口，拿回一份报告。                         |
| **`/compact`**  | 压缩当前上下文，用摘要启动新会话。                               |

## 决策树

在边界处自上而下地走。第一个**是**胜出。

**1. 能在当前会话里继续吗？** 两件事之一成立答案就是是：下一阶段需要本阶段作为 **primary source**，或者剩余的 smart zone（约 150k token）足够装下下一阶段。追问 → 实现是典型的"是"：实现需要的是推理过程的原文，而不是它的摘要。继续零成本、零损失，所以在考虑任何其他选项之前先排除它。

**2. 上下文对接下来的事无关紧要吗？** 这个会话里的一切 —— 探索、决策、死胡同 —— 都可以丢弃吗？如果是，**`/clear`**。它是棋盘上最便宜的一步：不花时间，还归还整个窗口。`/clear` 也不是终结 —— 旧会话仍可恢复。

做错的代价是单向的。清掉一份*相关*的上下文，你就丢了构建成果背后的**为什么**，再怎么回读 diff 也找不回来。

**3. 需要交接（handoff）吗？** tuanzii:handoff 用途很窄。只有当你：

- 要切换到**新的 harness**（Claude → Codex），
- 要搬到**新的目录**或仓库，
- 要把工作交给**同事**，
- 或者在**阶段中途**发现一个支线任务，想分叉出去又不想让手头的事脱轨，

才需要它。

这份清单就是全部条件。tuanzii:handoff 买到的是**可携带性** —— 一份能移动的文件。如果没有东西要移动，你就不需要它。

**4. 这个任务能无人值守（AFK）完成吗？** 它的范围是否收得足够紧，能在你离开键盘、无人指挥的情况下跑完？那就派给 **subagent**，当前会话原封不动。自动化评审是典型场景：agent 读 diff、交报告，期间不需要你。

**5. 否则，`/compact`。** 上下文相关、harness 相同、目录相同、而且你需要留在环里 —— 决策树最终落在这里，而且经常落在这里。给它传一句指令（`/compact 我们接下来要 QA 这块区域`），好让摘要保留下一阶段需要的东西。

`/compact` 是**默认项，不是第一选择**。它待在底部，是因为上面四个问题都更便宜或更精确。从这里起步的常见失败模式是：新会话对某个被摘要压扁的决策信心满满地犯错。

## Primary 与 secondary source

除**继续**之外的每一步，都把 **primary source** 变成了 **secondary source** —— 真实发生的会话，被它的摘要取代。这笔交易永远是同一个形状：

| 来源                            | 信息量 | 噪声 | 腾挪空间 |
| ------------------------------- | ------ | ---- | -------- |
| Primary（继续）                  | 完整   | 多   | 少       |
| Secondary（`/compact`、handoff） | 有损   | 少   | 多       |

这就是为什么问题 1 排在最前。只有当留下的代价超过收益时，你才该付这份有损的代价。

## 这些是判断力的问题

这些问题不是客观的 —— 每个都带着品味的成分，同一个边界换一天可能走向两个方向。价值在于**按顺序**问它们，在边界上问，而不是在工作进行到一半时问。
