# Triage Labels

Skills 以五个标准 triage 角色来表达。本文件把这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| 标准角色 label | 本 tracker 的 label | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不做处理 |

当某个 skill 提到某个角色时（例如"应用 AFK-ready 的 triage label"），使用本表中对应的 label 字符串。

编辑右列以匹配你实际使用的词汇。
