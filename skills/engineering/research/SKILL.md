name: research
description: 针对高可信度一手来源调查一个问题，并把发现沉淀为仓库里的 Markdown 文件。当用户想调研某个主题、收集文档或 API 事实、或把阅读跑腿活委派给后台 agent 时使用。触发词：“调研”、“research”、“查一下”。
---

派一个**后台 agent** 去做调研，这样你可以一边继续干活一边让它读资料。

它的职责：

1. 对照**一手来源**调查问题——官方文档、源代码、规范、第一方 API——而不是关于它们的二手文章。每个论断都要追溯到拥有它的源头。
2. 把发现写进一个 Markdown 文件，每条论断注明出处。
3. 保存到仓库里已有同类笔记的位置；遵循现有约定，如果没有约定，就放在一个合理的地方并说明放在哪里。
